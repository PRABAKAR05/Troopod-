# Purelane Shopify Theme — Build Notes

## Theme Architecture

This theme is a **Shopify Online Store 2.0** theme built by converting an existing exact visual clone of the Purelane prototype. Every visual decision comes from the source clone — no redesign has been performed.

## ⚠️ Known Limitations & Merchant Notes

### 1. Multi-product Bundle Purchasing
The **Bundles section** and **Combos section** are **visual only**. The CTA buttons link to a URL set by the merchant (collection, page, or product page).

**To enable real bundle add-to-cart:**
- Install the free [Shopify Bundles app](https://apps.shopify.com/shopify-bundles), create a bundle product, and link its URL in the block's "CTA URL" setting.
- Or use [Bundler](https://apps.shopify.com/bundler-product-bundles) / [Fast Bundle](https://apps.shopify.com/fast-bundle) for more flexibility.

### 2. Product Images
If products have no uploaded images, the theme falls back to the SVG illustration system from the original clone, matched by `product.type`:
- `kitchen` → kitchen cleaner SVG
- `laundry` → laundry SVG
- `floor` → floor cleaner SVG
- `toilet` / `bathroom` → toilet cleaner SVG
- `hand` → handwash SVG
- `dish` → dishwash SVG
- Anything else → tall bottle SVG fallback

### 3. Reviews
Reviews are manually editable blocks in the Theme Editor. If you install **Judge.me**, **Yotpo**, or **Okendo**, replace the `purelane-reviews.liquid` section content with the app embed code from those services, keeping the same `data-scene="1"` attribute on the outer `<section>`.

### 4. SVG Background Animations (Performance)
The water animation uses pure SVG + CSS keyframes (no `<feTurbulence>` filters). This is intentional — the filters in the original prototype caused severe frame drops. The current approach is smooth at 60fps on all devices.

### 5. Navigation Links
Go to **Online Store → Navigation → Main menu** in Shopify Admin to configure the nav links that appear in the header.

### 6. Footer Links
Create two navigation menus in Shopify Admin:
- `footer-shop` — for the "Shop" column
- `footer-about` — for the "About" column

## Deploying With Shopify CLI

```bash
# 1. Install Shopify CLI if not installed
npm install -g @shopify/cli @shopify/theme

# 2. Log in (already done)
shopify auth login

# 3. Navigate to theme folder
cd c:/Users/PRABAKAR/Desktop/mern/trood/shopify-theme

# 4. Push theme to your store (creates a new unpublished theme)
shopify theme push

# 5. Or push and open in Theme Editor to preview
shopify theme dev
```

## Theme Editor Configuration Checklist

After upload, do the following in the Theme Editor:

1. **Hero section** → Set products for each slide (or leave blank for SVG fallback)
2. **Hero section** → Set CTA URLs for "Shop now" and "How it works"
3. **Product Grid** → Select a collection from the dropdown
4. **Combos** → Set "CTA URL" on each combo block to your bundle product/collection URL
5. **Bundles** → Set "CTA URL" on each tier to your bundle destination
6. **Announcement ticker** → Edit ticker items one-per-line
7. **Navigation** → Configure main-menu, footer-shop, footer-about menus in Shopify Admin
